# Taxi Booking System – Java

## Overview
A console-based Taxi Booking System developed using Java and Object-Oriented Programming (OOP) concepts.

## Features
- Book a taxi between pickup and drop locations.
- Allocate an available taxi based on proximity.
- Resolve ties using the taxi's total earnings.
- Calculate fares based on travel distance.
- Track taxi availability and earnings.
- Display taxi booking history.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections Framework (`List`)

## How to Run
1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Compile the Java files:

   `javac *.java`

4. Run the program:

   `java Main`

## Concepts Practiced
- Classes and objects
- Encapsulation
- Constructors and methods
- Lists and object relationships
- Conditional logic and taxi allocation
